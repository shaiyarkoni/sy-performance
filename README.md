# SY Performance

אתר תדמית לעסק אימוני כוח וביצועים, עם דף בית בעברית ופאנל ניהול תוכן.

## הרצה

```bash
npm run dev
```

האתר יעלה ב-http://localhost:3000

## כניסה לניהול

לוחצים על אייקון גלגל השיניים בפינת הפוטר, או נכנסים ישירות ל-http://localhost:3000/admin
הסיסמה מוגדרת בקובץ `.env.local` תחת `ADMIN_PASSWORD`.

בפאנל אפשר לערוך את כל הטקסטים באתר, להעלות ולהחליף תמונות בכל סקשן, ולהוסיף או למחוק
מסלולים, תעודות, ממליצים, קהלי יעד ומאמרים. לחיצה על "שמור שינויים" מעדכנת את האתר מיד.

## איך זה בנוי

- **Next.js 16** (App Router) + TypeScript + Tailwind CSS v4
- **כל התוכן** יושב בקובץ אחד: `data/content.json`. הפאנל קורא וכותב אליו
- **תמונות** שמועלות מהפאנל נשמרות ב-`public/uploads/`
- **טופס צור קשר** לא שומר נתונים בשרת. הוא מרכיב הודעה ופותח את וואטסאפ
  עם המספר שמוגדר בפאנל תחת "פרטי התקשרות"
- **ההגנה על הניהול** היא קוקי חתום (`src/lib/auth.ts`) שנבדק ב-`src/proxy.ts`
  לפני כל בקשה ל-`/admin` או ל-`/api/admin`

## מבנה התיקיות

```
data/content.json          כל תוכן האתר
public/placeholders/        תמונות ברירת מחדל עד שמעלים אמיתיות
public/uploads/             תמונות שהועלו מהפאנל
src/app/                    דפים: בית, מאמר, ניהול, התחברות
src/components/site/        סקשנים של דף הבית
src/components/admin/       עורך התוכן
src/lib/                    טיפוסים, קריאה/כתיבה לתוכן, אימות, וואטסאפ
src/proxy.ts                שומר הסף של אזור הניהול
```

## לפני העלאה לאוויר

אירוח על Vercel לא מאפשר כתיבה לדיסק, ולכן העלאת תמונות ושמירת תוכן לא יעבדו שם כמו שהם.
צריך להעביר את `src/lib/content.ts` ואת `src/app/api/admin/upload/route.ts` לאחסון ענן
(למשל Vercel Blob יחד עם מסד נתונים מנוהל). לחלופין, אירוח על שרת עם דיסק כתיב
(VPS או Docker עם volume) יעבוד בלי שינוי קוד.

בכל מקרה, לפני העלאה יש להחליף את `ADMIN_PASSWORD` ואת `ADMIN_SESSION_SECRET` לערכים חדשים.
